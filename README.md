## 📌 About the Internship

The internship at W3villa Technologies provided practical exposure to software development through requirement-based tasks, project implementation, debugging, deployment, and computer vision data annotation.

During the internship, I worked with Functional Requirement Documents (FRDs), developed and enhanced a task management application, worked with the MERN stack, and performed assigned video annotation tasks using CVAT.

The development work initially involved **TaskFlow**, a task management application based on the assigned requirements. I later evolved the application into **ORBIQ**, a modern productivity-focused workspace with enhanced task management, analytics, authentication, subscription-related functionality, and deployment support.

The internship also included practical work with CVAT, where assigned video data was annotated using bounding boxes and polygon annotations. The completed work was reviewed and corrections were made wherever required.

## 🚀 Project Work — TaskFlow → ORBIQ

### TaskFlow

TaskFlow was the initial task management application developed from the assigned Functional Requirement Document.

The project involved:

- User authentication
- User and profile management
- Task management
- REST APIs
- Database integration
- Frontend and backend connectivity
- Requirement-based feature implementation

### ORBIQ

The application was later evolved into **ORBIQ — Modern Productivity Workspace**.

Key areas included:

- Mission Control dashboard
- Task and mission management
- Task priorities and states
- Analytics and productivity tracking
- Authentication and profile management
- Subscription-related functionality
- REST API integration
- MongoDB database integration
- Production deployment
- HORIZON and PULSAR-based application concepts

## 🏗️ System Architecture

The ORBIQ application follows a client-server architecture.

    USER
      │
      ▼
    React + Vite Frontend
    (Vercel)
      │
      │ REST API / Axios
      ▼
    Node.js + Express Backend
    (Render)
      │
      ▼
    MongoDB Atlas
    Database

Additional services were used for authentication, email communication, scheduled tasks, and other application functionality.
